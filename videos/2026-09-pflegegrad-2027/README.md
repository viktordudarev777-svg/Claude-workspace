## Факты, на которых построен ролик

Все — из Referentenentwurf **Pflegeneuordnungsgesetz (PNOG)**, Bundesministerium für Gesundheit, **05.06.2026**.
Статус на 06.09.2026: **проект, кабинетом министров не принят**. В ролике это сказано прямым текстом.

- Планируемые пороги баллов с 01.01.2027: **PG 1 — 12,5 → 15**, **PG 2 — 27 → 30**, **PG 3 — 47,5 → 50**.
- PG 4 (70) и PG 5 (90) — без изменений.
- **Bestandsschutz**: уже признанный Pflegegrad не понижают только из-за новых порогов.
- Переходное правило: заявление оценивают по праву, действующему **на день подачи**. Подано до **31.12.2026** → старые пороги, даже если Begutachtung пройдёт в 2027.
- Pflegegeld 2026: PG 2 — **347 €/мес**, PG 3 — 599 €/мес (не менялись с 01.01.2025). При PG 1 Pflegegeld не выплачивается, есть Entlastungsbetrag **131 €/мес**.
- Sozialverband VdK рекомендует подавать Erstantrag не откладывая.

## Производство

Всё сгенерировано внутри репозитория, стоковые материалы не использовались — визуал целиком векторный/CSS, музыка синтезирована.
По лицензии синтезированного голоса вопрос не закрыт — см. ../2026-09-grundsicherung-2026/VERIFY.md.

- `script.json` — текст, субтитры, привязка к сценам
- `build/tts.py` — синтез речи (Piper, голос `ru-irinia-medium`, женский), замер длительностей → `build/timeline.json`
- `build/scene.html` + `scene.css` + `render.js` — вся графика и покадровая анимация
- `build/render_video.py` — покадровый рендер через Chromium → x264
- `build/audio.py` — фоновая музыка (Am–F–C–G), ducking под голос, лимитер
- `build/cover.py` — обложка

Пересобрать: `python3 build/tts.py && python3 build/render_video.py && python3 build/audio.py && ./build/mux.sh`

## Заменить озвучку на студийную

Голос в ролике синтезирован локально (Piper). Если нужен голос уровня ElevenLabs:

1. Озвучьте текст из `SCRIPT.md` (тайминги указаны построчно).
2. Сохраните по одному WAV на строку: `build/pro/s01.wav` … `build/pro/s12.wav` (16-bit PCM).
3. `./build/revoice.sh` — пересчитает тайминги, перерисует анимацию и соберёт новый mp4.

## Произношение

Немецкие термины в поле `tts` записаны кириллицей со знаком ударения (U+0301) — без него espeak-ng
ставит русское ударение на последний слог и `Pflegegrad` звучит как «пфлегеграˊд».
Словарь терминов и способ проверки новых слов — в [`../PRONUNCIATION.md`](../PRONUNCIATION.md).
