# Произношение немецких терминов в озвучке

Голос синтезируется русской моделью (Piper `ru-irinia-medium`), фонемизация — espeak-ng.
Немецкие слова записываются в поле `tts` кириллицей: латиницу русский фонемизатор читает по буквам или пропускает.

Проблема: для незнакомых слов espeak ставит русское ударение по умолчанию — **на последний слог**.
Поэтому `пфлегеград` читалось как «пфлегегрА́д» вместо `Pflégegrad`.

Решение: знак ударения U+0301 (комбинируемый акут) после ударной гласной. espeak-ng его понимает.
В субтитрах и на экране акутов нет — они только в `tts`.

## Русские слова, где espeak ошибается

| Слово | Ставит | Нужно |
|---|---|---|
| году | го́ду | году́ |
| сорока (род. п.) | соро́ка | сорока́ |
| сорок | соро́к | со́рок |
| стоит (= имеет цену) | стои́т | сто́ит |
| арендодателю | арендо́дателю | арендода́телю |
| платите (изъяв. накл.) | плати́те | пла́тите |

## Как проверить новое слово

```python
from piper.phonemize_espeak import EspeakPhonemizer
ph = EspeakPhonemizer()
p = lambda v, t: "".join("".join(s) for s in ph.phonemize(v, t))
print(p("de", "Pflegegrad"))      # эталон
print(p("ru", "пфле́геград"))     # что скажет голос
```
Сравнивать позицию `ˈ` — она должна совпадать со слогом немецкого эталона.
